## Summary

Add contract expiry alert system, display remaining contract days warning, and improve daily check-in UX.

## Changes

### Contract alert

```markdown
- Check remaining contract days for each worker based on their active contract
- Show visual warning on the work and care calendar when remaining contract days drop below a configurable threshold
- Send automatic alert email to accountants when a contract is about to expire
```

### Daily check-in UX

```markdown
- Automatically pre-fill the current date in the daily execution submission field
```
